## Running

Needs Python 3.11+ with Tk (on Homebrew Python, `brew install python-tk`).

```sh
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python3 main.py   # open a .csv/.xlsx usage file, set the tariffs, click Compare
bin/test          # run the test suite
```
